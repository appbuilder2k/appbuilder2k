# Full-stack engineer · C# / .NET / Angular

I build web products from the database and API through to the user interface. My current focus is reusable backend infrastructure that lets developers spend more time on the features that make their products distinct.

## Featured work — DotNetMono

**A modular ASP.NET Core backend foundation.** Start with health checks, structured errors, and request tracing, then add SQL Server access, account management, and email as the product needs them.

| Explore | What it shows |
| --- | --- |
| [DotNetMono.Core on NuGet](https://www.nuget.org/packages/DotNetMono.Core/0.1.0) | ASP.NET Core conventions for health, rate limiting, error responses, and request correlation |
| [DotNetMono.Data.Dapper on NuGet](https://www.nuget.org/packages/DotNetMono.Data.Dapper/0.1.0) | Parameterized SQL access, transactions, and explicit migrations |
| [DotNetMono.Users on NuGet](https://www.nuget.org/packages/DotNetMono.Users/0.1.0) | Account registration, verification, and password recovery |
| [DotNetMono.Email on NuGet](https://www.nuget.org/packages/DotNetMono.Email/0.1.0) | A reusable SMTP module |

I built an Angular starter configurator and a sample API that consumes the published packages. The sample exercises account flows and adds a developer project workspace on top of the reusable modules.
